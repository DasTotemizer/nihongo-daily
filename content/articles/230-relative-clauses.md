In English we say "the book that I read". In Japanese, the description goes in front of the noun, with no word for "that". Any plain verb, or a whole short sentence, can sit there.

## Verb + noun

::: breakdown
ja: {昨日|きのう} {読|よ}んだ {本|ほん}
en: the book (I) read yesterday
- {昨日|きのう} {読|よ}んだ = read yesterday: a complete little sentence
- {本|ほん} = book: the noun it describes
:::

::: example
ja: よく {行|い}く {店|みせ}
en: a shop (I) often go to
:::

::: example
ja: {日本語|にほんご} を {話|はな}す {人|ひと}
en: a person who speaks Japanese
:::

## Then use it like any noun

The whole phrase now behaves like one noun. You can put は, を or だ after it.

::: breakdown
ja: {昨日|きのう} {読|よ}んだ {本|ほん} は {面白|おもしろ}かった。
en: The book (I) read yesterday was interesting.
- {昨日|きのう} {読|よ}んだ {本|ほん} = the book (I) read yesterday
- は = as for
- {面白|おもしろ}かった = was interesting
:::

::: example
ja: {毎朝|まいあさ} コーヒー を {飲|の}む {人|ひと} が {多|おお}い。
en: Many people drink coffee every morning.
note: Literally: people who drink coffee every morning are many.
:::

## Sentence order: the verb comes last

Japanese sentences end with the verb. Everything else, the time, the place, the object, comes first, usually in that order. The particles tell you each word's job, so the order is flexible, but the verb stays at the end.

::: breakdown
ja: {昨日|きのう} {駅|えき} で {友|とも}だち に {会|あ}った。
en: (I) met a friend at the station yesterday.
- {昨日|きのう} = yesterday: when
- {駅|えき}で = at the station: where
- {友|とも}だちに = a friend: who you met
- {会|あ}った = met: the verb, last
:::

::: callout
title: Read from the end
When a long sentence confuses you, find the last verb first. Then find the noun right before each smaller verb. Those nouns are being described.
:::

::: mistake
wrong: {本|ほん} {昨日|きのう} {読|よ}んだ
right: {昨日|きのう} {読|よ}んだ {本|ほん}
why: The description always comes before the noun it describes.
:::
