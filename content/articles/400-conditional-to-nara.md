English uses *if* for everything. Japanese has four conditionals, each with its own flavour. Start with と and なら.

## と: whenever this, then that

と describes a natural, automatic result. Put it after the plain form, present tense.

::: example
ja: ボタン を {押|お}す と、ドア が {開|あ}く。
en: If you press the button, the door opens.
:::

::: example
ja: {春|はる} に なる と、{桜|さくら} が {咲|さ}く。
en: When spring comes, the cherry trees bloom.
:::

::: callout
title: No wishes after と
Because と describes things that just happen, the second half can't be a request, a wish or a plan. Use たら for those.
:::

## なら: if that's the case

なら takes something already in the conversation and says what follows from it. After a noun, use なら directly.

::: dialogue
A: {京都|きょうと} に {行|い}きたい ん だ。 // I want to go to Kyoto.
B: {京都|きょうと} なら、{秋|あき} が いい よ。 // If it's Kyoto, autumn is best.
:::

::: breakdown
ja: {明日|あした} {雨|あめ} なら、{行|い}かない。
en: If it's rain tomorrow, I won't go.
- {明日|あした} = tomorrow
- {雨|あめ}なら = if it's rain
- {行|い}かない = won't go
:::

You can put なら after a verb too: {行|い}くなら, if you are going.

::: mistake
wrong: {駅|えき} に {着|つ}く と、{電話|でんわ} して ください。
right: {駅|えき} に {着|つ}いたら、{電話|でんわ} して ください。
why: A request can't follow と. たら is next lesson's conditional and works here.
:::
