## A rule of thumb

- と: automatic results. Push the button and the door opens.
- ば: general conditions. If it's cheap, I'll buy it.
- たら: once something happens. When I get home, I'll call.
- なら: given what you just said. If you're going to Kyoto, go in autumn.

## The same idea, four ways

::: example
ja: {春|はる} に なる と、{暖|あたた}かく なる。
en: When spring comes, it gets warm. (always)
:::

::: example
ja: {春|はる} に なれば、{暖|あたた}かく なる。
en: If spring comes, it'll get warm. (general condition)
:::

::: example
ja: {春|はる} に なったら、{旅行|りょこう} しよう。
en: When spring comes, let's go on a trip. (a plan)
:::

::: example
ja: {春|はる} なら、{桜|さくら} を {見|み}に {行|い}く と いい よ。
en: If it's spring, you should go and see the cherry blossom. (advice on that topic)
:::

::: callout
title: When unsure
Choose たら. It covers the widest range and rarely sounds wrong.
:::
