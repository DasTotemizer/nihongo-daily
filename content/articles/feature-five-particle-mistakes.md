Particles carry a lot of meaning for their size. These five mistakes come up again and again. Each comes from thinking in English.

## 1. Using に for where an action happens

::: mistake
wrong: カフェ に {勉強|べんきょう} する。
right: カフェ で {勉強|べんきょう} する。
why: Actions happen で a place. に is for where you go, or where something is.
:::

## 2. Putting に on today and tomorrow

::: mistake
wrong: {明日|あした} に {行|い}く。
right: {明日|あした} {行|い}く。
why: Relative times like {明日|あした} and {今日|きょう} take no particle.
:::

## 3. Forgetting を for the place you move through

::: mistake
wrong: {公園|こうえん} で {散歩|さんぽ} する。
right: {公園|こうえん} を {散歩|さんぽ} する。
why: Both can be heard, but with walking and crossing, を marks the space you move along.
:::

## 4. Marking a liked thing with を

::: mistake
wrong: {猫|ねこ} を {好|す}き だ。
right: {猫|ねこ} が {好|す}き だ。
why: {好|す}き is an adjective, not a verb, so it cannot take を.
:::

## 5. Using は with question words

::: mistake
wrong: {何|なに} は ある？
right: {何|なに} が ある？
why: A question word is unknown information, which always takes が.
:::

::: callout
title: A quick check
Before you choose, ask: is this word the place, the tool, the target, the object or the topic? Each job has its particle.
:::
