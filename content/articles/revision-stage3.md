## The toolkit

::: vocab
- {行|い}きたい | want to go | たい
- {行|い}こう | let's go | volitional
- {行|い}ける | can go | potential
- {行|い}かなきゃ | have to go | must
- {行|い}って も いい | may go | permission
- {行|い}く と {思|おも}う | I think I'll go | quoting
- {連|つ}れて {行|い}って くれた | kindly took me | favour
- {行|い}って ください | please go | request
:::

## A short story

::: example
ja: {日本|にほん} に {行|い}きたかった けど、お{金|かね} が なかった。
en: I wanted to go to Japan, but I didn't have the money.
:::

::: example
ja: だから、{毎日|まいにち} {働|はたら}かなければ ならなかった。
en: So I had to work every day.
:::

::: example
ja: {一年|いちねん} {後|ご}、やっと {行|い}ける よう に なった。
en: A year later, I was finally able to go.
:::

::: example
ja: {友|とも}だち が {空港|くうこう} まで {送|おく}って くれた。
en: My friend kindly took me to the airport.
:::

::: quiz
? match potential
q: Match each form to its meaning.
- {読|よ}みたい = want to read
- {読|よ}もう = let's read
- {読|よ}める = can read
- {読|よ}まなきゃ = have to read
why: Each pattern changes the verb in its own way.

? choice giving-receiving
q: Which means "My friend taught me"?
- {友|とも}だち が {教|おし}えて くれた *
- {友|とも}だち に {教|おし}えて あげた
- {友|とも}だち が {教|おし}えて あげた
why: The favour came to you, so it is てくれた.
:::
