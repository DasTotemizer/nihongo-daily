## なる: become

Use に before なる with nouns and な-adjectives. For い-adjectives, change い to く.

::: example
ja: {先生|せんせい} に なりたい。
en: I want to become a teacher.
:::

::: example
ja: {部屋|へや} が きれい に なった。
en: The room became clean.
:::

::: example
ja: {寒|さむ}く なった ね。
en: It's got cold, hasn't it.
:::

## する: make it so, or decide on it

The same pattern with する means you make something that way.

::: example
ja: {音|おと} を {小|ちい}さく して ください。
en: Please make the sound quieter.
:::

With a noun and に, する means *decide on*. This is how you order in a café.

::: dialogue
{店員|てんいん}: ご{注文|ちゅうもん} は? // What would you like?
{客|きゃく}: コーヒー に します。 // I'll have a coffee.
:::

## ことになる and ことにする

After a verb, ことになる means it has been decided for you, and ことにする means you decided it yourself.

::: example
ja: {来月|らいげつ}、{大阪|おおさか} に {行|い}く こと に なった。
en: It's been decided that I'm going to Osaka next month.
:::

::: example
ja: {毎日|まいにち} {走|はし}る こと に した。
en: I've decided to run every day.
:::

## ようになる: come to be able to

::: example
ja: {日本語|にほんご} が {話|はな}せる よう に なった。
en: I've become able to speak Japanese.
:::

::: mistake
wrong: {暑|あつ}い に なった。
right: {暑|あつ}く なった。
why: い-adjectives change い to く before なる.
:::
