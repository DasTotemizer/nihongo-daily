Japanese has one past tense, and it ends in た or だ. It covers "ate", "have eaten" and "did eat" all at once.

## る-verbs: drop る, add た

::: example
ja: {食|た}べる → {食|た}べた
en: eat → ate
:::

::: example
ja: {見|み}る → {見|み}た
en: see → saw
:::

## う-verbs: it depends on the last sound

This is the part to learn as a chart. The ending changes depending on the verb's final kana.

::: vocab
- {話|はな}す → {話|はな}した | spoke | す → した
- {書|か}く → {書|か}いた | wrote | く → いた
- {泳|およ}ぐ → {泳|およ}いだ | swam | ぐ → いだ
- {飲|の}む → {飲|の}んだ | drank | む, ぶ, ぬ → んだ
- {遊|あそ}ぶ → {遊|あそ}んだ | played | ぶ → んだ
- {買|か}う → {買|か}った | bought | う, つ, る → った
- {待|ま}つ → {待|ま}った | waited | つ → った
- {帰|かえ}る → {帰|かえ}った | went home | る → った
:::

It looks like a lot, but there are only five patterns: した, いた, いだ, んだ and った. Saying the verbs aloud helps, because the changes make them easier to pronounce.

## The exceptions

::: vocab
- {行|い}く → {行|い}った | went | not いた
- する → した | did | irregular
- {来|く}る → {来|き}た | came | irregular
:::

{行|い}く ends in く, so you might expect {行|い}いた. It is {行|い}った instead. This one exception catches everyone at least once.

## The past negative

The negative form ends in ない, which works like an い-adjective. So the past negative swaps ない for なかった, for every verb.

::: example
ja: {食|た}べない → {食|た}べなかった
en: don't eat → didn't eat
:::

::: breakdown
ja: {昨日|きのう} は {何|なに}も {食|た}べなかった。
en: I didn't eat anything yesterday.
- {昨日|きのう}は = as for yesterday
- {何|なに}も = nothing, anything: used with a negative
- {食|た}べなかった = didn't eat
:::
