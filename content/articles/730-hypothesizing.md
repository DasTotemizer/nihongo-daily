## わけ: the reason, the conclusion

わけ is a noun, so you attach it like one. On its own it means *reason*.

::: example
ja: {遅|おく}れた わけ を {教|おし}えて。
en: Tell me why you were late.
:::

## わけだ: so that's why

::: example
ja: {毎日|まいにち} {練習|れんしゅう} して いる。{上手|じょうず} な わけ だ。
en: She practises every day. No wonder she's good.
:::

## わけではない: it's not that

::: example
ja: {嫌|きら}い な わけ では ない けど、あまり {食|た}べない。
en: It's not that I dislike it, but I don't eat it much.
:::

## わけがない: there's no way

::: example
ja: そんな こと、できる わけ が ない。
en: There's no way I can do something like that.
:::

## わけにはいかない: I can't, because it wouldn't be right

::: example
ja: {約束|やくそく} した から、{行|い}かない わけ に は いかない。
en: I promised, so I can't not go.
:::

## とする: suppose that

A sentence plus とする sets up a hypothetical: *let's say*.

::: breakdown
ja: {宝|たから}くじ が {当|あ}たった と したら、{何|なに} を する?
en: Supposing you won the lottery, what would you do?
- {宝|たから}くじが{当|あ}たった = won the lottery
- としたら = supposing that
- {何|なに}をする = what would you do
:::

::: example
ja: {今|いま} {出|で}た と して も、{間|ま}に{合|あ}わない。
en: Even if we left now, we wouldn't make it.
:::

::: quiz

why: わけがない flatly denies a possibility.
