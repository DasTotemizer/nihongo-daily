## はず: it should be so

はず is a noun meaning *expectation*. Attach it like a noun: the plain form, な after な-adjectives, の after nouns.

::: example
ja: {彼|かれ} は もう {着|つ}いて いる はず だ。
en: He should have arrived by now.
:::

::: example
ja: {鍵|かぎ} は ここ に ある はず なのに、ない。
en: The key should be here, but it isn't.
:::

::: example
ja: そんな はず は ない。
en: That can't be right.
:::

## べき: ought to

Put べき after the dictionary form of a verb. With する, both するべき and すべき are used.

::: breakdown
ja: {約束|やくそく} は {守|まも}る べき だ。
en: You ought to keep your promises.
- {約束|やくそく}は = promises: the topic
- {守|まも}るべき = ought to keep
- だ = it is so
:::

::: example
ja: もっと {早|はや}く {言|い}う べき だった。
en: I should have said so sooner.
:::

## べく and べからず: formal and old

べく means *in order to* and appears in formal writing. べからず means *must not* and appears on old-fashioned signs.

::: example
ja: {夢|ゆめ} を {叶|かな}える べく、{毎日|まいにち} {努力|どりょく} して いる。
en: I work hard every day in order to achieve my dream.
:::

::: example
ja: {芝生|しばふ} に {入|はい}る べからず。
en: Keep off the grass.
:::

::: callout
title: はず or べき?
はず is about what you expect to be true. べき is about what is right to do.
:::
