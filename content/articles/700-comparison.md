## {方|ほう} and より: comparing two things

Put the winner with の{方|ほう}が, and the loser with より.

::: breakdown
ja: {犬|いぬ} より {猫|ねこ} の {方|ほう} が {好|す}き だ。
en: I like cats more than dogs.
- {犬|いぬ}より = than dogs
- {猫|ねこ}の{方|ほう}が = cats: the side that wins
- {好|す}きだ = like
:::

To ask which is better, use どちら or どっち.

::: dialogue
A: {夏|なつ} と {冬|ふゆ}、どっち が {好|す}き? // Summer or winter, which do you prefer?
B: {冬|ふゆ} の {方|ほう} が {好|す}き。 // I prefer winter.
:::

## ほうがいい: you'd better

A past verb plus ほうがいい gives advice. A negative plus ほうがいい advises against.

::: example
ja: {早|はや}く {寝|ね}た ほう が いい よ。
en: You'd better go to bed early.
:::

::: example
ja: {無理|むり} しない ほう が いい。
en: You'd better not overdo it.
:::

## {方|かた} as "way of doing"

The ます stem plus {方|かた} means *the way to do it*.

::: example
ja: この {漢字|かんじ} の {読|よ}み{方|かた} が わからない。
en: I don't know how to read this kanji.
:::

## によると: according to

::: example
ja: ニュース に よる と、{電車|でんしゃ} が {止|と}まって いる そう だ。
en: According to the news, the trains have stopped.
:::

によって means *depending on* or *by*.

::: example
ja: {人|ひと} に よって {考|かんが}え{方|かた} が {違|ちが}う。
en: Ways of thinking differ from person to person.
:::
