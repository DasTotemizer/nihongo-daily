You have met は, which sets the topic. Its close cousin も works in exactly the same position, but adds one idea: *also*, *too*, *as well*.

## Swap は for も

::: example
ja: {私|わたし} は {学生|がくせい} だ。
en: I am a student.
:::

::: breakdown
ja: {田中|たなか}さん も {学生|がくせい} だ。
en: Mr Tanaka is a student too.
- {田中|たなか}さん = Mr Tanaka
- も = also, too: replaces は
- {学生|がくせい}だ = is a student
:::

も replaces は. You never write them together: は も is always wrong.

## Too, and not either

With a negative, も means "not either".

::: example
ja: {私|わたし} も {学生|がくせい} じゃない。
en: I'm not a student either.
:::

## The shortest answer

Because Japanese leaves out what is obvious, も makes a complete reply all by itself.

::: dialogue
Aki: {今日|きょう}は {休|やす}みだ。 // Today's my day off.
Ren: {私|わたし}も。 // Me too.
:::

::: mistake
wrong: {私|わたし} は も {学生|がくせい} だ。
right: {私|わたし} も {学生|がくせい} だ。
why: も takes the place of は. Using both is one of the most common beginner slips.
:::
