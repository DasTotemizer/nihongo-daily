Some particles do not connect a noun to a verb. They connect nouns to each other. The three most common are と, や and の.

## と: a complete list

と joins nouns like "and". It means the list is complete: these things, and nothing else.

::: breakdown
ja: パン と {牛乳|ぎゅうにゅう} を {買|か}った。
en: (I) bought bread and milk.
- パン = bread
- と = and: the list is complete
- {牛乳|ぎゅうにゅう} = milk
:::

と also means "with" when it follows a person.

::: example
ja: {友|とも}だち と {映画|えいが} を {見|み}た。
en: (I) watched a film with a friend.
:::

## や: an example list

や also joins nouns, but it hints that there are more. Think "things like" or "and so on".

::: example
ja: パン や {牛乳|ぎゅうにゅう} を {買|か}った。
en: (I) bought things like bread and milk.
note: Maybe eggs too. や leaves the list open.
:::

## の: belonging and description

の links two nouns so the first describes the second. Most often it shows who owns something, like 's in English.

::: breakdown
ja: {先生|せんせい} の {本|ほん}
en: the teacher's book
- {先生|せんせい} = teacher
- の = links the owner to the thing
- {本|ほん} = book
:::

::: example
ja: {日本語|にほんご} の {先生|せんせい}
en: a Japanese teacher (a teacher of Japanese)
:::

::: example
ja: {私|わたし} の {友|とも}だち
en: my friend
:::

::: callout
title: Read の backwards
In AのB, the main thing is B. A tells you which B. So {日本|にほん}の{車|くるま} is a car, and it is from Japan.
:::

::: mistake
wrong: {私|わたし} {本|ほん}
right: {私|わたし} の {本|ほん}
why: Two nouns cannot sit side by side to show ownership. の is needed between them.
:::
